# PaperBridge Product Vision
PaperBridge resurrects 1960s optical punch-cards and bubble sheets into a zero-friction, offline-first physical-to-digital bridge for elder medication adherence and caregiver analytics.

## Core Rules
- Never require smartphones, logins, or cloud uploads for the end-user filling out the paper card.
- Always provide a 1-click "Sample Scanned Card" fallback on the web UI so judges without a printer can test the full optical pipeline.
